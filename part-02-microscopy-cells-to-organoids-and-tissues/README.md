# Part 2 — Microscopy: from cells to organoids and tissues

Animation code for the video "Microscopy: From Cells to Organoids and Tissues" (48 scenes).

- `animation/ep2_intro.py`, `ep2_part1.py`, `ep2_part2.py` – scene specifications.
- `animation/mk_ep2_data.py`, `mk_figtours.py` – helper scripts that build the data and figure-tour scenes.
- `animation/scenes/<scene-name>/scene.html` – the generated scene page; `cues.json` holds the narration-synced timings.
- Shared tools: [`../shared/animation-kit`](../shared/animation-kit).
