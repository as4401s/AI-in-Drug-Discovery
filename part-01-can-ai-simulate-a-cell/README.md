# Part 1 — Can AI simulate a cell?

Animation code for the video "Can AI simulate a cell?" (53 scenes).

- `animation/specs_ep1a.py`, `specs_ep1b.py`, `specs_ep1c.py`, `ep1_part2.py`, `ep1_part34.py` – scene specifications (what appears on screen and when).
- `animation/scenes/<scene-name>/scene.html` – the generated scene page; `cues.json` holds the narration-synced timings.
- `animation/render_all_e1a.sh` – example render commands.
- Shared tools: [`../shared/animation-kit`](../shared/animation-kit).
